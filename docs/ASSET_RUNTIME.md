# Runtime asset manifest

scripts/pack_assets.py converts complete raw Blender animation directories to public/assets/manifest.json and Phaser JSON atlases. Root owns packer/public outputs. Renderer may read asset IDs only from FACTIONS unit/building definitions and environment map presentation. No game mechanics in manifest.

Manifest schemaVersion1, projection64x32. `atlases:[{key,image,data}]` contains URLs to PNG and Phaser hash atlas JSON. `assets[id]` unit/building entry has kind,width,height,anchor:[x,y],pages:[atlasKey],animations:{state:{frames:number,fps:number,loop:boolean,directions:{'0':[frameName,...],...}}}. Frames may span pages; construct frameName->atlasKey from Phaser texture frames or know asset page by search once at load. Sprite ground origin = anchorX/width, anchorY/height. 1source pixel per world pixel at zoom1. Direction0..7 matches sim facing. Unit state idle/walk/attack/death; buildings idle/construction/death (3constructionframes by progress). Entity removed1.2sec after death, death animation must show pose in that duration.

Environment entry kind environment,id,width,height,anchor,file,image(URL). Proposed IDs tile-grass-0..3, tile-dirt-0..2,tile-stone,tree-pine,tree-oak,ore,stump,ruin-pillar,ruin-ring (agent may add; coordinate). Store environmental sprites in same world depth ordering when tall. Ground tiles may use a RenderTexture after load for performance. Static actor scale1 unless explicit art calibration proves otherwise. Fog must overlay sprites without leaking unknown entities. Selection rings/bars remain lightweight vector UI overlays. Missing assets are acceptable only before final gate; final build must fail validation if required assets absent.
