# Hold Position verification

The current production bundle is `index-9PMVYv2m.js`. H and the Hold position button assign a shared defensive order for either faction. Units attack visible enemies within their own weapon range without pursuing. Eligible automatic abilities remain available during in-range combat; doubles inherit the order. X retains the previous stop behavior, and subsequent movement or other orders release hold. This addresses loss of defensive positioning identified in work/faction-balance-study/ABLATION.md. It does not claim to balance the factions.

The three new semantic tests cover a visible out-of-range enemy without pursuit, an in-range attack, release through movement and stop, ranged support, defensive doubles, and an out-of-range preferred unit that must not mask a reachable building. All 61 tests pass; current-verification.json and hold-tests.txt bind the result to current source hashes. The production build was reproduced independently with all 67 files matching (BUILD_REPRODUCTION.md).
