# Playable tutorial

Requirement 1 is a playable tutorial covering harvesting, construction, recruitment and a first battle. Choose First battle tutorial in Play mode and begin a match with the selected faction, seed and map size. The objective card follows delivered resources, a finished barracks, a recruited melee soldier and defeat of a nearby practice enemy. Show me selects relevant owned units and centers the camera. The opponent does not plan in this mode. Ordinary commands retain costs, population, ownership and visibility checks; the first fight cannot start until the economy objectives are complete. Restart returns to the existing match menu.

Core progress is serializable and available to the learner only, so terminal matches follow the same objectives. Training units use current faction definitions. The practice enemy uses a visible open destination near home and reduced health for an introductory fight. Ordinary skirmishes stay unchanged.
