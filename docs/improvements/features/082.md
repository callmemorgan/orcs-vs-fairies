# 082: Faction selection and accepted-order acknowledgments

Requirement: faction-specific selection and order acknowledgments.

Each of the six factions now has a procedural vocal call, with its own pitch, formant and waveform. Selection uses one syllable; accepted orders use two. Repeated or empty selections and enemy-only selections stay silent. These are synthesized calls rather than recorded dialogue or unavailable system speech voices. Existing trusted-gesture unlock and mute remain in force.

Scene mouse/hotkeys, HUD and improvement-host commands all use the common dispatchPlayerCommand function. Its module is byte-identical to published controls011 commit 43ce2cc98e4f93dcba92740d19984803598274f0 (blob 1501e0a187aa04e1bc4f0fd6286d56210c349ca3). It notifies the scene-specific voice observer once only when ordinary issueCommand accepts an action. Foreign scenes, rejected ownership/paused commands, and interceptor actions that never reach ordinary acceptance do not produce that acknowledgment. The observer and audio graph dispose once on either shutdown or destruction. Presentation audio does not enter simulation state.
