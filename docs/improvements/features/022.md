# 022: Deposited resource income per minute

The requirement is resource income per minute beside totals. Wood, ore and crystal now each show the amount deposited during the last 60 seconds. The tooltip states the window and excludes spending and refunds. Early-match values use the full 60-second window rather than projecting a short burst into a rate.

An opt-in simulation rule captures ordinary gather deposit events on each tick, before the HUD refresh can miss them. It retains only 60 seconds of deposits and exposes only the observing side's totals. The same rule loads in the browser and terminal through the HUD rules entry. The client adds compact inline labels beside each total.

Claude simplify completed using opus[1m], xhigh and the default 9000-second timeout; the reported model was claude-opus-5-5[1m]. It shared an observation type and shortened the event guard without changing the window, amounts or privacy. The actual diff and handoff were inspected. HEAD/index and unrelated files were preserved; the manifest records no permission denials.
