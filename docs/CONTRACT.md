# Integration contract
Root owns src/core/types.ts, src/core/content.ts, src/main.ts, package files and integration. Do not edit files outside your ownership.

Simulation agent owns src/core/simulation.ts and pathfinding helpers. Exports createGame(faction: FactionId, seed?: number): GameState; stepGame(state: GameState, dt:number):void; issueCommand(state:GameState, side:Side, command:Command):boolean; canPlace(state,side,role,x,y):boolean; isVisible(state,side,x,y):boolean. Optional exports permitted. Fixed-step caller at 0.05 seconds. stepGame clears events at start. 48x48 world, faction0 starts near (8,8), opponent near (39,39). Entity progress 0..1 indicates construction; units progress=1. Entities dead hp<=0 stay briefly for death animation, then removed. Winner null until hq destroyed. IDs globally unique across resources/entities. visibility cell floor(y)*width+floor(x).

Renderer agent owns src/game/GameScene.ts and helpers within src/game only. Default exported Phaser.Scene class GameScene. Constructor options object {state:GameState; onSelection:(ids:number[])=>void; onNotice:(text:string)=>void}. Public selected:number[], buildRole:BuildingRole|null, paused:boolean, setBuildRole(role), centerOn(x,y), restart(state). Uses simulation API above, calls fixed steps. Exposes state. Handles controls, selection, orders, camera, fog, minimap if convenient (coordinate with UI agent). Placeholder art in this gate. Render dimensions adapt parent. Camera world iso tile width64,height32. Screen projection x=(x-y)*32,y=(x+y)*16; origin can be offset. Draw ground 48x48. Separate coordinates from simulation. Emit selected IDs and notices; optional window debug instrumentation report to root. Do not integrate DOM HUD.

UI agent owns src/ui/Hud.ts and src/ui/style.css only. Export mountShell(root:HTMLElement, onStart:(faction:FactionId)=>void): {showMenu:()=>void; showGame:()=>void; update:(state:GameState, selected:number[], callbacks:HudCallbacks)=>void; notice:(text:string)=>void}. Export HudCallbacks {build:(role:BuildingRole)=>void;train:(role:UnitRole)=>void;ability:()=>void;stop:()=>void;pause:()=>void;restart:()=>void;center:(x:number,y:number)=>void}. Shell contains #game-canvas parent for Phaser; menu faction selection starts play. HUD DOM fixed around game canvas, display resources, selection info, queues, command buttons, tooltips, keyboard help, minimap (canvas drawing state fog), pause and result overlays. Update every ~100ms. Do not recreate buttons each update if it breaks input. Main owns Phaser creation and main update loop; GameScene owns simulation stepping. Use imports ../core/types and ../core/content. Content exports FACTIONS record. Renderer handles game canvas and keyboard.

Tests agent owns tests/ only. Test simulation API. Keep fixtures realistic, explicit and limited. No weakening assertions to match bugs. Report failures to simulation agent/root.
